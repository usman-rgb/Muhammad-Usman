# ZiaAI Agent

A fast, responsive AI desktop agent powered by Groq API with streaming text output, voice interaction, avatar-based UI, and direct system task execution capabilities.

## Overview

ZiaAI is a desktop AI assistant that combines large language model capabilities with system-level task execution. It features real-time streaming responses, text-to-speech output, and an avatar-based user interface for a natural interaction experience.

## Key Features

- Groq API-powered LLM responses
- Real-time streaming text output
- Voice interaction (TTS)
- Avatar-based UI
- Direct system task execution
- Fast response times

## Tech Stack

- **Language:** Python
- **API:** Groq API
- **Core:** LLM, Streaming, TTS
