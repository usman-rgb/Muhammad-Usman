# Bitcoin Price Prediction using LSTM

Time-series forecasting model to predict Bitcoin prices with high accuracy using Long Short-Term Memory networks.

## Overview

This project implements an LSTM-based deep learning model for cryptocurrency price prediction. It analyzes historical Bitcoin price data, applies time-series preprocessing, and generates future price forecasts with quantified confidence intervals.

## Key Features

- LSTM neural network architecture
- Historical price data analysis
- Time-series preprocessing pipeline
- Price trend forecasting
- Pandas-based data engineering
- Model evaluation metrics

## Tech Stack

- **Language:** Python
- **Framework:** TensorFlow
- **Core:** LSTM, Time-Series Analysis, Pandas
