# Harmonic Origin

Audio analysis and music generation project exploring harmonic patterns with deep learning models.

## Overview

Harmonic Origin is a deep learning project that analyzes audio data to discover harmonic patterns and generate music. It uses TensorFlow models to understand musical structures and create novel compositions.

## Key Features

- Audio signal analysis
- Harmonic pattern recognition
- Deep learning-based music generation
- Interactive Streamlit interface
- TensorFlow model pipeline

## Tech Stack

- **Language:** Python
- **Framework:** TensorFlow, Streamlit
- **Core:** Deep Learning, Audio Analysis
