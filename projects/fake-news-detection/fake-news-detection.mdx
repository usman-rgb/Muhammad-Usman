# Fake News Detection System

NLP model to detect fake news with high precision using text classification and feature extraction pipelines.

## Overview

This system uses natural language processing and deep learning to classify news articles as real or fake. It employs text preprocessing, feature extraction, and classification pipelines to achieve high precision in misinformation detection.

## Key Features

- Real/fake news binary classification
- Text preprocessing pipeline
- Feature extraction (TF-IDF, embeddings)
- Multiple classifier comparison
- High precision detection
- Scikit-learn integration

## Tech Stack

- **Language:** Python
- **Libraries:** Scikit-learn
- **Core:** NLP, Deep Learning
