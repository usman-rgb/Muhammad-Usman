# Weather Application

Real-time weather forecasting app with beautiful UI, live API integration, and location-based forecasts.

## Overview

A weather application that fetches real-time weather data via API integration. Features a polished user interface, location-based forecasting, and multi-day weather predictions.

## Key Features

- Real-time weather data
- Location-based forecasting
- Live API integration
- Beautiful responsive UI
- Multi-day forecasts
- Temperature, humidity, wind data

## Tech Stack

- **Languages:** JavaScript, Python
- **Core:** REST API Integration
