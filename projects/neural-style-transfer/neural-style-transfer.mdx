# Neural Style Transfer

Artistic style transfer using VGG-19 convolutional neural networks to blend artistic styles onto photographs.

## Overview

This project implements neural style transfer based on the VGG-19 architecture. It extracts artistic style features from one image and content features from another, blending them to create stunning artistic photographs.

## Key Features

- VGG-19 based feature extraction
- Content and style loss optimization
- Multiple artistic style support
- High-resolution output
- TensorFlow implementation

## Tech Stack

- **Language:** Python
- **Framework:** TensorFlow
- **Core:** CNN, VGG19
