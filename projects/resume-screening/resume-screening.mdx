# AI-Powered Resume Screening System

Automated system to screen and rank candidate resumes using NLP and Deep Learning, significantly reducing HR processing time.

## Overview

This system automates the resume screening process for HR departments. It uses NLP techniques including TF-IDF vectorization and deep learning models to analyze, score, and rank candidate resumes against job descriptions, dramatically reducing manual review time.

## Key Features

- Automated resume parsing and extraction
- TF-IDF based text vectorization
- Deep learning ranking model
- Job description matching
- Candidate scoring and ranking
- Streamlit web interface

## Tech Stack

- **Language:** Python
- **Framework:** Streamlit
- **Core:** NLP, Deep Learning, TF-IDF
