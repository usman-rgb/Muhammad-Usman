# Personalized TimeTable Generator

AI-powered timetable generation system that creates personalized, conflict-free academic schedules based on student preferences, course loads, and constraints.

## Overview

This project uses AI optimization and constraint-solving algorithms to generate optimal academic timetables. Students can input their course preferences, schedule constraints, and other requirements, and the system produces a conflict-free timetable automatically.

## Key Features

- Conflict-free schedule generation
- Student preference-based optimization
- Course load balancing
- Constraint satisfaction solving
- Interactive Streamlit UI

## Tech Stack

- **Language:** Python
- **Framework:** Streamlit
- **Core:** AI Optimization, Constraint Solving
