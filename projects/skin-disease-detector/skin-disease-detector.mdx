# Skin Disease Detector

CNN-based model for classifying multiple skin conditions from dermoscopic images with clinical-grade accuracy.

## Overview

A convolutional neural network model trained on dermoscopic imagery to detect and classify various skin diseases. The model achieves clinical-grade accuracy and can assist dermatologists in early diagnosis of skin conditions.

## Key Features

- Multi-class skin disease classification
- Dermoscopic image analysis
- CNN architecture with transfer learning
- Clinical-grade accuracy
- Image preprocessing pipeline

## Tech Stack

- **Language:** Python
- **Framework:** Keras
- **Core:** CNN, Computer Vision
