# AI Multi-Disease Detection

Deep learning system to detect multiple diseases from medical images and patient symptoms with high recall.

## Overview

A comprehensive medical AI system that can detect multiple diseases from both medical imagery and symptom data. Built with PyTorch and CNN architectures, it achieves high recall rates crucial for medical screening applications.

## Key Features

- Multi-disease classification
- Medical image analysis
- Symptom-based detection
- CNN-based deep learning model
- High recall optimization
- PyTorch implementation

## Tech Stack

- **Language:** Python
- **Framework:** PyTorch
- **Core:** Deep Learning, CNN, Medical AI
