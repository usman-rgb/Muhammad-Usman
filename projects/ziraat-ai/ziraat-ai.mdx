# Ziraat AI

An intelligent agricultural AI assistant that provides crop recommendations, disease detection, weather-based guidance, and yield predictions for Pakistani farmers.

## Overview

Ziraat AI is designed to help Pakistani farmers make data-driven decisions. It combines computer vision for crop disease detection, NLP for natural language queries, and deep learning models for yield prediction and crop recommendations.

## Key Features

- Crop disease detection via image analysis
- Crop recommendation engine
- Weather-based agricultural guidance
- Yield prediction models
- Natural language query support
- Interactive Streamlit dashboard

## Tech Stack

- **Language:** Python
- **Framework:** Streamlit
- **Core:** Deep Learning, Computer Vision, NLP
