# NFT Marketplace on XRPL

Decentralized NFT marketplace built on XRP Ledger with smart contracts and Web3 wallet integration.

## Overview

A decentralized marketplace for non-fungible tokens (NFTs) built on the XRP Ledger blockchain. Features smart contract interaction, Web3 wallet integration, and a user-friendly interface for minting, buying, and selling NFTs.

## Key Features

- XRP Ledger blockchain integration
- NFT minting functionality
- Buy/sell marketplace
- Web3 wallet connection
- Smart contract interaction
- Transaction history

## Tech Stack

- **Language:** JavaScript
- **Core:** Blockchain, XRPL, Web3
